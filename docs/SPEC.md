# PSDTool Viewer 仕様書

PSDTool 形式で構成された PSD ファイルを読み込み・表示・編集する Windows 11 専用アプリケーション。

## 技術構成

| 項目 | 内容 |
|---|---|
| UI | WPF（.NET 10 / C#）、Fluent テーマ、Mica 背景 |
| 内部処理 | C#（PSD 読み書き・合成処理は自前実装） |
| 自動更新 | Velopack + GitHub Releases（`MitamaHaruki/PSDToolViewer`） |
| 配布 | 自己完結型。インストーラ（管理者権限不要）とポータブル版 zip |
| ライセンス | MIT |

## 画面

- **タイトルバー（自作）**：アプリアイコン、メニューバー、最小化・最大化・閉じる
  - 最大化時に画面上部へはみ出さない
  - Windows 11 のスナップレイアウトに対応
  - タイトルは「PSDTool Viewer - ファイル名」。未保存時は印を付ける
- **ツールバー（タイトルバーの下、ウィンドウ全幅）**：ファイル読込み／フォルダ読込み／書き出し／クリップボードにコピー／透明余白をトリミング ｜ フォルダを作成／ラジオボタン切替／強制表示切替／削除／名前の変更
- **左：レイヤー欄、右：プレビュー**（設定で左右入れ替え可）
- レイヤー欄にサムネイルを表示（設定で切替、初期は表示）
- 読込み中・保存中は進捗付きのローディングを表示し、操作を止める（読込みはキャンセル可）
- ライト／ダーク テーマ対応

### メニュー

- ファイル：新規／開く／フォルダを開く／最近使ったファイル／上書き保存／名前を付けて保存／書き出し／終了
- 編集：元に戻す／やり直し／クリップボードにコピー／フォルダを作成／ラジオボタン切替／強制表示切替／削除／名前の変更／すべて選択
- 表示：拡大／縮小／ウィンドウに合わせる／100%／すべて展開／すべて折りたたむ
- ツール：設定
- ヘルプ：更新を確認／バージョン情報（製作者：三玉春樹 / はるたまプロジェクト、アカウント：https://x.com/MitamaHaruki）

## 名前と記号（PSDTool 準拠）

- 各レイヤー／フォルダは **内部名**（出力用。`!` `*` を含む）と **表示名**（記号なし）を持つ
- 読込み時は先頭の `!` `*` を記号として読み取り、表示名からは除く
- ラジオボタン化／強制表示の切替で、内部名の先頭の記号が付いたり消えたりする
- `*` と `!` は同時に付けない（片方を付けるともう片方は外れる）
- 名前の変更は表示名を編集し、内部名は「記号＋新しい表示名」になる
- PSD・専用形式の保存と書き出しには内部名を使う
- `*`：同じ階層の `*` 付き同士で 1 つだけ表示（ラジオボタン）。初期選択は表示状態のもの（複数／なしの場合は一番上）
- `!`：常に表示し、チェックボックスは出さない
- 記号なし：チェックボックスで表示を切り替える
- レイヤーとフォルダのどちらにも適用する

## 読込み

- **ファイル読込み／開く**：psd・専用形式（`.ptv`）・png
  - png は、何も開いていなければ新規として開き、開いていれば一番下に追加する
- **PSD から使う情報**：画像、名前、表示状態、不透明度（塗り含む）、描画モード、クリッピング、レイヤーマスク
  - 調整レイヤー・レイヤー効果・テキストの再描画は行わず、PSD 内の画像として扱う
  - 対応は 8bit RGB の PSD のみ（それ以外はエラー表示）
  - PSDTool の反転指定（`:flipx` 等）やお気に入り機能は対象外
- **フォルダ読込み**：フォルダはフォルダ、png はレイヤーとして読み込む
  - 名前の自然順（1, 2, 10…）で並べ、先頭をツリーの一番上（最前面）にする
  - 左上基準で配置し、キャンバスは最大の幅×高さ
  - フォルダへの書き戻しは行わない
- **アプリ外からの D&D**
  - png：一番下に追加（ツリー上にドロップした場合はその位置）。複数はファイル名順。キャンバスより大きい場合はキャンバスを拡張
  - psd／`.ptv`／フォルダ：読込み直し（未保存なら確認ダイアログ）

## 保存・出力

| 操作 | 形式 | 透明余白トリミング |
|---|---|---|
| 上書き保存／名前を付けて保存 | PSD または `.ptv` | しない |
| 書き出し | PSD を別名で出力（編集中のファイルは切り替わらない） | ON のとき行う（全レイヤーを重ねた範囲が基準） |
| クリップボードにコピー | 現在のプレビュー（PNG） | しない |
| プレビューから D&D | `image.png`（ファイル出力・貼り付けの両方に対応） | ON のとき行う（現在のプレビューが基準） |

- PSD 保存時、表示状態は各レイヤーの表示フラグとして保存し、統合画像には現在のプレビューを書き込む
- 「未保存」扱いにするのは構造の変更（追加・削除・移動・名前変更・記号変更）のみ。表示の切替は含めない

### 専用形式（`.ptv`）

ZIP 形式。`document.json`（ツリー構造・内部名・表示状態・不透明度など）と、レイヤー画像・マスク画像の PNG を格納する。

## 操作

- 行クリックで選択。Ctrl＋クリックで選択／解除、Shift＋クリックで範囲選択
- チェックボックス／ラジオボタンのクリック（または Space キー）で表示を切替
- ドラッグで選択中の項目を移動（フォルダ中央にドロップで中へ、行の上端・下端で前後へ）
- フォルダ作成：選択中の項目のすぐ上（同じ階層）。未選択なら一番下
- 複数選択時の記号切替：選択中すべてに付いていれば外し、それ以外は全部に付ける
- 名前の変更はツリー上でその場編集（F2／ボタン／メニュー）
- 元に戻す／やり直しに対応。削除時の確認ダイアログは出さない
- 右クリックメニュー：ラジオボタン切替／強制表示切替／削除／名前の変更
- プレビュー：初期はウィンドウに合わせて表示。Ctrl＋ホイールで拡大縮小、中ボタンドラッグまたは Space＋ドラッグで移動、左ドラッグで画像を D&D

## 設定

左右入れ替え、サムネイル表示、テーマ（システム／ライト／ダーク）、プレビュー背景（市松／白／黒／グレー）、起動時の更新確認

## 配布・更新

- 起動時にバックグラウンドで更新を確認し、新しい版があれば通知（「更新して再起動」／「後で」）
- ファイル関連付けは `.ptv` のみ。PSD は「プログラムから開く」の候補に登録するだけ
- コード署名なし、UI は日本語のみ
